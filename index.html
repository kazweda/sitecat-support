SiteCat とは / About

SiteCat は、ウェブサイトの死活監視とリンク切れ検出を行う iOS 向けアプリです。 サイトマップを使ったリンクの自動収集・検証や、HTTP ステータスの確認などの機能を提供していました。

  • ウェブサイトのアップタイム監視（HTTP ステータスチェック）
  • リンク切れ検出（サイトマップベースのクロール）
  • マルチサイト管理
  • クラウドデータ同期（Firebase）

SiteCat was an iOS app for website uptime monitoring and broken link detection. It offered sitemap-based link crawling, HTTP status checks, and cloud data sync.

  • Website uptime monitoring (HTTP status checks)
  • Broken link detection (sitemap-based crawling)
  • Multi-site management
  • Cloud data sync (Firebase)
